Kebijakan Privasi

Terakhir diperbarui: 31 Oktober 2026 · Berlaku untuk Ada Reminder v2.0.0

Ada Reminder dibuat dengan prinsip sederhana: aplikasi pengingat tidak perlu mengetahui apa pun tentangmu. Tidak ada akun, tidak ada pelacakan, dan tidak ada data alarm yang dikirim ke server.

Data yang disimpan

Aplikasi menyimpan data berikut secara lokal di komputermu:

  • Alarm dan jadwal — nama alarm, jam, tanggal, hari pengulangan, dan status aktif.
  • Preferensi — durasi tunda dan batas waktu dering.
  • Nada dering pilihanmu — file audio yang kamu impor disalin ke folder data aplikasi.
  • Jadwal Windows — file XML dan entri Windows Task Scheduler yang diperlukan agar alarm tetap berbunyi.
  • Log teknis — catatan singkat untuk membantu mencari masalah jika alarm gagal dijadwalkan.

Semua data tersebut berada di %APPDATA%\AdaReminder. Kamu dapat membuka, memeriksa, mencadangkan, atau menghapusnya sendiri kapan saja.

Apa yang tidak dilakukan

  • Tidak membuat akun atau meminta alamat email.
  • Tidak mengirim data alarm, file audio, atau log ke internet.
  • Tidak memakai analitik, iklan, atau pelacak pihak ketiga di dalam aplikasi.
  • Tidak menjual atau membagikan data kepada pihak lain.

Windows Task Scheduler

Agar alarm tetap berbunyi saat aplikasi ditutup, Ada Reminder membuat jadwal di Windows Task Scheduler. Jadwal ini hanya berisi waktu, nama alarm, dan perintah untuk membuka jendela dering. Windows menjalankannya secara lokal di perangkatmu. Kamu bisa menghapusnya lewat aplikasi (tombol Hapus), menu Pengaturan → Perbaiki jadwal, atau Task Scheduler.

Nada dering pihak ketiga

Kamu bertanggung jawab atas file audio yang kamu impor. Pastikan kamu memiliki hak untuk memakai file tersebut. File hanya disalin ke folder data lokal dan tidak diunggah ke mana pun.

Situs web ini

Halaman unduhan ini adalah situs statis. Situs tidak memasang cookie pelacak atau formulir pendaftaran. Untuk kenyamanan tampilan, situs memuat font dari Google Fonts; koneksi ke Google dapat mencatat alamat IP dan informasi teknis standar sesuai kebijakan privasi Google. Aplikasi desktop Ada Reminder sendiri tidak memuat font atau konten dari internet.

Menghapus data

Untuk menghapus seluruh data, tutup aplikasi, hapus jadwal lewat menu Pengaturan, lalu hapus folder %APPDATA%\AdaReminder. Salinan aplikasi yang dibuat otomatis berada di %LOCALAPPDATA%\AdaReminder dan juga bisa dihapus.

Perubahan kebijakan

Jika kebijakan ini berubah, tanggal pembaruan di bagian atas akan disesuaikan. Perubahan besar akan dicatat di catatan rilis atau README yang disertakan dalam paket unduhan.

Pertanyaan

Karena tidak ada data yang dikumpulkan, sebagian besar pertanyaan privasi bisa dijawab dengan memeriksa folder data lokalmu. Untuk hal lain, gunakan kanal distribusi tempat kamu mengunduh aplikasi ini.
